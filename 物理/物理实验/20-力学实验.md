# 专题20 力学实验

## 考点定位

掌握高中力学核心实验的原理、装置、数据处理和误差分析，能迁移到创新实验情境。

## 知识清单

| 实验 | 核心依据 | 关键测量 |
| --- | --- | --- |
| 探究速度随时间变化 | $\Delta x=aT^2$ | 纸带点距、周期 |
| 探究弹力与形变量 | $F=kx$ | 弹力、伸长量 |
| 验证平行四边形定则 | 合力与分力等效 | 力的大小和方向 |
| 探究 $a$ 与 $F,m$ 关系 | $F=ma$ | 合力、质量、加速度 |
| 探究平抛运动 | 水平匀速、竖直自由落体 | 轨迹坐标 |
| 验证机械能守恒 | $mgh=\frac12mv^2$ | 高度、瞬时速度 |
| 验证动量守恒 | $\sum p=\sum p'$ | 质量、碰撞前后速度 |
| 单摆测重力加速度 | $T=2\pi\sqrt{l/g}$ | 摆长、周期 |

## 核心方法

- 纸带某点瞬时速度用邻近相等时间内平均速度：$v_n=(x_{n+1}-x_{n-1})/(2T)$。
- 探究多个变量关系时采用控制变量法；通过图像判断正比关系比只比较两组数据可靠。
- 验证机械能守恒可约去质量；纸带第一点未必速度为零，应根据实验设计决定表达式。
- 动量实验优先测位移与时间比值，若各段运动时间相同可用位移替代速度参与比例计算。

## 典型实验分析

### 探究加速度与力、质量的关系

小车法中先平衡摩擦力，随后改变小车质量时通常无需重新平衡。若用砝码重力近似小车所受拉力，应满足砝码质量远小于小车及其载荷总质量；使用力传感器可避免此近似。

### 单摆测重力加速度

测摆线悬点到摆球球心的距离为摆长。小角度释放，测多次全振动总时间求周期。作 $T^2-l$ 图像，斜率 $k=4\pi^2/g$，故 $g=4\pi^2/k$。

## 代表性例题

单摆摆长 $1.00\,\mathrm m$，50次全振动用时 $100\,\mathrm s$，则 $T=2.00\,\mathrm s$，$g=4\pi^2l/T^2\approx9.87\,\mathrm{m/s^2}$。

## 易错提醒

- “平衡摩擦力”时不要悬挂砝码，且应让小车连着纸带运动。
- 平抛轨迹坐标原点应取抛出点，坐标纸竖直方向需用重垂线校准。
- 单摆计时应从摆球经过平衡位置开始，往返一次才是一次全振动。

## 自测

1. 验证机械能守恒时，重物质量测量不准一定影响验证结果吗？
2. $a-F$ 图像不过原点且横轴有正截距，常见原因是什么？

::: details 答案
1. 若等式两边均含质量并约去，则不影响。 2. 未完全平衡摩擦力或仍存在阻力。
:::
