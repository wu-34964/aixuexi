# 专题21 电学实验

## 考点定位

掌握电表读数与改装、伏安法测电阻、描绘伏安特性曲线、测电源电动势和内阻及多用电表使用。

## 知识清单

### 电表改装

- 表头满偏电流 $I_g$、内阻 $R_g$，满偏电压 $U_g=I_gR_g$。
- 改装电压表需串联分压电阻：$R=U/I_g-R_g$。
- 改装电流表需并联分流电阻：$R=I_gR_g/(I-I_g)$。
- 校准时用标准表对照，示数偏差不能通过“修改数据”消除。

### 伏安法测电阻

- 电流表内接：$R_{测}=U/I=R_x+R_A$，结果偏大，适合大电阻。
- 电流表外接：电流表测得总电流，结果偏小，适合小电阻。
- 限流接法结构简单；分压接法能使待测电压从接近零开始连续调节，适合要求范围大或待测电阻较大的情形。

![伏安法测电阻的电流表内接法与外接法对比](/physics/voltmeter-methods.svg)

### 常见实验

- 描绘小灯泡伏安特性时使用分压电路，多测几组数据；灯丝温度升高，电阻增大，图线不是直线。
- 测电源 $E,r$：由 $U=E-Ir$，作 $U-I$ 图像，纵截距为 $E$、斜率绝对值为 $r$。
- 多用电表测电阻：机械调零 → 选挡 → 欧姆调零 → 测量 → 指针靠近中值时读数 → 用毕置于交流高压挡或 OFF。

## 核心设计方法

1. **选电表**：安全前提下使指针偏转达到满偏的约 $1/3$ 以上，兼顾量程和精度。
2. **选变阻器**：限流考虑允许电流与总阻值；分压优先选总阻值较小、额定电流足够的器件。
3. **实物连线**：先画原理图，再按电流路径连接；开关闭合前使待测支路处于安全状态。
4. **故障判断**：电流表示数为零先查断路；电流过大查短路或变阻器接法；用电势法逐段定位。

## 代表性例题

测一只约 $5\,\Omega$ 的电阻，电流表内阻 $0.5\,\Omega$，电压表内阻 $3\,\mathrm{k\Omega}$。内接法相对误差约 $R_A/R_x=10\%$；外接法受电压表分流影响约 $R_x/R_V\approx0.17\%$，应选外接法。

## 易错提醒

- 实物连接和拆线均应断开开关；电表正负接线柱不能接反。
- 欧姆表测量带电电路会损坏仪表，测量在路电阻前应断电并隔离待测元件的一端。
- $U-I$ 图像纵轴若不从零开始，读取截距和斜率时仍要使用坐标真实数值。
- 用伏安法测电源参数时，电表内阻会造成系统误差；应按实际电路推导误差方向。

## 自测

1. 测小电阻应优先采用电流表内接还是外接？
2. 描绘小灯泡伏安特性为什么不宜只测两组数据？
3. 测电源得到的 $U-I$ 图像斜率为 $-0.8\,\mathrm{V/A}$，内阻是多少？

::: details 答案
1. 外接。 2. 小灯泡是非线性元件，多点才能呈现电阻随温度变化的曲线。 3. $0.8\,\Omega$。
:::
