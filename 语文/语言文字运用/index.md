# 语言文字运用

这一模块考查的不是孤立规则，而是在真实语境中准确、连贯、得体地使用语言。

## 知识地图

1. [词语与成语](/语文/语言文字运用/词语与成语)：辨析词义、色彩、对象与搭配。
2. [辨析并修改病句](/语文/语言文字运用/辨析并修改病句)：从句子主干到逻辑关系逐层排查。
3. [语句衔接与表达效果](/语文/语言文字运用/语句衔接与表达效果)：把握话题、顺序、照应和修辞。
4. [压缩仿写与图文转换](/语文/语言文字运用/压缩仿写与图文转换)：按指令提取、重组和表达信息。

建议按顺序学习；每学完一页，收集一道错题并标注错因属于“知识不清”还是“语境判断失误”。
