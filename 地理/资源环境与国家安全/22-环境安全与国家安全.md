# 专题 22 环境安全与国家安全

## 考点定位

环境安全、跨境污染、生态保护与全球环境治理。

## 核心概念

环境安全、突发环境事件、生态安全、全球环境治理。

## 知识框架

- 环境安全
- 突发环境事件
- 生态安全
- 全球环境治理

## 基础知识清单

- 环境安全是自然环境及其服务功能处于可支撑经济社会发展的状态，风险在可接受范围内。
- 突发环境事件具有时间突然、危害集中和扩散快等特点，需要风险源管理、监测预警和应急处置。
- 污染物可经大气、河流、海洋和生物迁移跨越行政边界，治理需要区域和国际合作。
- 生态保护红线、自然保护地和生态修复有助于维护重要生态功能与生物多样性。
- 全球气候变化、臭氧层破坏和生物多样性减少具有共同性，但各国责任和能力存在差异。
- 全球环境治理需要国际规则、资金技术支持、信息共享和公众参与，并遵循共同但有区别的责任。

## 图表判读与规律总结

1. **先定位对象**：明确图表展示的空间范围、时间尺度和核心变量。
2. **再描述特征**：从数量、变化、分布、差异或组合关系中提取证据。
3. **后解释原因**：围绕本专题的“环境安全—突发环境事件—生态安全—全球环境治理”建立因果链。
4. **最后组织答案**：先写结论，再用图表信息和地理原理支撑。

## 关键能力拓展与答题模板

- 环境风险分析按风险源—传播途径—承灾体—后果展开。
- 跨境问题回答监测、通报、标准、联合处置与补偿机制。
- 生态工程评价要考察长期维护、地方生计和生态适宜性。

> [!TIP] 综合题表达
> 使用“区域条件 → 地理过程 → 主要特征 → 影响或措施”的顺序；每一点都写出明确对象和因果关系。

## 易错提醒

> 环境安全不是绝对零风险，而是通过预防和治理把风险控制在可接受范围。

## 自测

**问题：** 上游发生水污染为什么需要流域协同治理？

::: details 参考答案
污染会沿水系扩散并影响下游，单个行政区无法独立控制全过程。
:::
