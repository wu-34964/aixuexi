# 专题 16 交通运输与区域发展

## 考点定位

运输方式、交通布局及其区域影响。

## 核心概念

运输方式、交通布局、交通对聚落影响、交通与区域发展。

## 知识框架

- 运输方式
- 交通布局
- 交通对聚落影响
- 交通与区域发展

## 基础知识清单

- 铁路、公路、水运、航空和管道运输各有速度、运量、成本、连续性和灵活性差异。
- 交通线布局受地形、地质、气候、水文等自然条件制约，也取决于经济、人口、技术和国家战略。
- 交通站点应考虑客货流、衔接条件、建设空间、城市联系和环境影响。
- 交通改善可降低运输成本、扩大市场、促进资源开发和产业集聚，并加强区域联系。
- 交通线可能改变聚落形态和商业网点布局；交通方式衰落也可能使原有节点地位下降。
- 重大交通工程评价要同时考虑经济、社会、生态和国家安全效益。

## 图表判读与规律总结

1. **先定位对象**：明确图表展示的空间范围、时间尺度和核心变量。
2. **再描述特征**：从数量、变化、分布、差异或组合关系中提取证据。
3. **后解释原因**：围绕本专题的“运输方式—交通布局—交通对聚落影响—交通与区域发展”建立因果链。
4. **最后组织答案**：先写结论，再用图表信息和地理原理支撑。

## 关键能力拓展与答题模板

- 运输方式选择根据货物性质、距离、时效、运量和运价。
- 山区交通选线尽量沿等高线、河谷和缓坡，并避开灾害区。
- 交通影响分析区分直接通达效应与后续产业人口变化。

> [!TIP] 综合题表达
> 使用“区域条件 → 地理过程 → 主要特征 → 影响或措施”的顺序；每一点都写出明确对象和因果关系。

## 易错提醒

> 交通建设不是区域发展的唯一条件；资源、市场、产业基础和政策同样重要。

## 自测

**问题：** 大宗、笨重、远距离且时效要求低的货物优先选什么运输？

::: details 参考答案
通常选择铁路或水运，具体取决于线路条件。
:::
