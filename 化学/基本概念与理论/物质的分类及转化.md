# 物质的分类及转化

## 考点定位

辨认分散系、纯净物和混合物；按物质类别预测性质；用“价态—类别”二维图设计转化路线。

## 核心知识清单

- 纯净物分为单质和化合物；化合物可分为氧化物、酸、碱、盐等。分类标准必须唯一且层级一致。
- 分散质粒子直径通常按溶液（小于 $1\,\mathrm{nm}$）、胶体（$1\sim100\,\mathrm{nm}$）、浊液（大于 $100\,\mathrm{nm}$）区分。
- 胶体能产生丁达尔效应；胶体粒子可透过滤纸而通常不能透过半透膜。
- 酸性氧化物通常与碱反应，碱性氧化物通常与酸反应；两性氧化物可与强酸、强碱反应。

## 重要规律与转化

同一元素可按“单质 $\rightarrow$ 氧化物 $\rightarrow$ 酸或碱 $\rightarrow$ 盐”建立类别链；价态改变一定涉及氧化还原，价态不变的类别转化通常是复分解或化合反应。

$$\ce{CaO + H2O -> Ca(OH)2}$$
$$\ce{CO2 + 2NaOH -> Na2CO3 + H2O}$$

## 典型方法与例题

**例** 如何鉴别胶体与溶液？

**解** 让一束可见光通过样品，从侧面观察；出现明亮光路的是胶体。不能用是否透明判断，因为部分胶体也透明。

## 易错提醒

- $ce{Na2O2}$ 与 $ce{NO2}$ 不是按组成机械判断的碱性、酸性氧化物。
- “能导电”不是电解质的定义；铜和石墨能导电但属于单质，不是电解质。

2. 胶体与浊液的本质区别是什么？
