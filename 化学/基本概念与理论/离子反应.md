# 离子反应

## 考点定位

判断电解质强弱、书写离子方程式、判断离子共存并分析离子检验与定量关系。

## 核心知识清单

- 电解质是在水溶液中或熔融状态能导电的化合物；强弱取决于电离程度，不取决于溶解度。
- 离子反应发生条件通常为生成沉淀、气体、弱电解质，或发生氧化还原、络合反应。
- 离子方程式遵循客观事实、质量守恒、电荷守恒和得失电子守恒。
- 强酸、强碱和可溶性盐拆成离子；单质、氧化物、气体、沉淀、弱电解质保留化学式。

## 重要反应与方法

$$\ce{H+ + OH- -> H2O}$$
$$\ce{CO3^2- + 2H+ -> CO2 ^ + H2O}$$
$$\ce{Fe^3+ + 3SCN- <=> Fe(SCN)3}$$

书写时按“写分子方程式—拆强电解质—删相同离子—查守恒”四步完成。判断共存还要注意无色、酸碱性和隐含氧化还原条件。

## 典型方法与例题

**例** 向 $ce{NaHCO3}$ 溶液中滴加少量 $ce{Ca(OH)2}$，不能只写 $ce{HCO3- + OH- -> CO3^2- + H2O}$，还应依据少量试剂的量比考虑生成 $ce{CaCO3}$ 沉淀。

## 易错提醒

- $ce{BaSO4}$ 难溶，但溶解部分完全电离，仍是强电解质。
- $ce{HCO3-}$ 与酸、碱均可反应；多元弱酸根的写法受试剂用量影响。

## 自测

1. 写出铝与强碱溶液反应的离子方程式。
2. $ce{Fe^3+}$、$ce{SCN-}$ 能否大量共存？

::: details 答案
1. $\ce{2Al + 2OH- + 2H2O -> 2AlO2- + 3H2 ^}$（水溶液也可写羟基合铝酸根形式）。2. 不能，会形成配合物。
:::
