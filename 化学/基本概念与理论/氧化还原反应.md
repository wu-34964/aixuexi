# 氧化还原反应

## 考点定位

判断氧化剂、还原剂和产物；比较氧化还原性；配平方程式并完成守恒计算。

## 核心知识清单

- 氧化还原反应的本质是电子转移，特征是元素化合价发生变化。
- 还原剂失电子、化合价升高、被氧化；氧化剂得电子、化合价降低、被还原。
- 同一反应中：转移电子总数相等，化合价升降总数相等。
- 氧化性强弱可由反应方向判断：氧化剂的氧化性通常强于氧化产物；还原剂的还原性通常强于还原产物。

## 配平与计算

用化合价升降法确定氧化剂、还原剂系数，再按原子和电荷守恒补齐。酸性条件常用 $ce{H+}$、$ce{H2O}$，碱性条件常用 $ce{OH-}$、$ce{H2O}$。

$$\ce{MnO4- + 5Fe^2+ + 8H+ -> Mn^2+ + 5Fe^3+ + 4H2O}$$

关系式计算抓住电子数：$n(e^-)=n(\text{氧化剂})\times\text{每粒子得电子数}$。

## 典型方法与例题

**例** $1\,\mathrm{mol}\,\ce{Cl2}$ 与足量热的浓碱反应时转移多少电子？

**解** 氯发生歧化，生成 $ce{Cl-}$ 和 $ce{ClO3-}$；按 $3\ce{Cl2}$ 转移 $5\,\mathrm{mol}$ 电子，故答案为 $\frac53\,\mathrm{mol}$。

## 易错提醒

- 有单质参加或生成的反应不一定都是氧化还原反应，如同素异形体转化。
- 转移电子数不是反应物所含价电子总数，只统计发生价态变化的电子。

## 自测

1. 在 $ce{2H2S + SO2 -> 3S + 2H2O}$ 中，氧化剂与还原剂物质的量之比是多少？
2. 配平酸性条件下 $ce{Cr2O7^2-}$ 氧化 $ce{I-}$ 的离子方程式。

::: details 答案
1. $1:2$。2. $\ce{Cr2O7^2- + 14H+ + 6I- -> 2Cr^3+ + 3I2 + 7H2O}$。
:::
