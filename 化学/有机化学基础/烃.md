# 烃

## 考点定位

掌握烷烃、烯烃、炔烃和芳香烃的结构、性质、命名、同分异构与反应类型。

## 核心知识清单

- 链状烷烃通式为 $ce{C_nH_{2n+2}}$，主要发生取代、氧化和裂化反应。
- 单烯烃、环烷烃常用通式 $ce{C_nH_{2n}}$；烯烃可发生加成、氧化和加聚。
- 单炔烃通式 $ce{C_nH_{2n-2}}$，碳碳三键使其能发生加成反应。
- 苯具有平面正六边形结构，碳碳键完全等同，易取代、难氧化，可在特定条件下加成。

## 重要反应

$$\ce{CH2=CH2 + Br2 -> CH2BrCH2Br}$$
$$\ce{C6H6 + Br2 ->[FeBr3] C6H5Br + HBr}$$
$$\ce{nCH2=CH2 ->[-催化剂-] [-CH2-CH2-]_{n}}$$

## 典型方法与例题

**例** 鉴别乙烷和乙烯可用溴水：乙烯加成使溴水褪色，乙烷在无光、常温条件下无明显反应；不能用燃烧现象作唯一证据。

## 易错提醒

烯烃使酸性高锰酸钾褪色是氧化反应而非加成；苯不能使溴水因化学反应褪色，但可萃取溴而使水层颜色变浅。
