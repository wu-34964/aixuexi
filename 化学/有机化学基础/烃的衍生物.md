# 烃的衍生物

## 考点定位

以官能团为主线掌握卤代烃、醇、酚、醛酮、羧酸和酯的性质及相互转化。

## 核心知识清单

- 卤代烃在强碱水溶液中发生水解，在强碱醇溶液、加热条件下发生消去。
- 醇可发生取代、消去、氧化和酯化；羟基所连碳上有氢时才可能被氧化为醛或酮。
- 苯酚显弱酸性，能与 $ce{NaOH}$ 反应，遇浓溴水生成白色沉淀，遇 $ce{FeCl3}$ 常显紫色。
- 醛基可被银氨溶液或新制氢氧化铜氧化；羧酸有酸性，与醇发生可逆酯化。
- 酯在酸或碱条件下水解，碱性水解较彻底，称皂化反应。

## 重要反应

$$\ce{CH3CH2OH + CuO ->[\Delta] CH3CHO + Cu + H2O}$$
$$\ce{CH3COOH + C2H5OH <=>[浓H2SO4][\Delta] CH3COOC2H5 + H2O}$$

## 典型方法与例题

**例** 检验卤代烃中的卤素：先在碱性水溶液中加热水解，冷却后加稀硝酸酸化，再加硝酸银；不能直接向水解碱液加硝酸银。

## 易错提醒

能发生银镜反应的不只有醛；甲酸、甲酸酯等也可能表现还原性。酯化反应中羧酸脱羟基、醇脱氢。
