# 物质的分离、提纯与鉴别

## 考点定位

依据状态、溶解度、沸点和化学性质选择分离提纯方法，设计有证据链的物质检验方案。

## 核心知识清单

| 方法 | 主要依据 | 典型对象 |
| --- | --- | --- |
| 过滤 | 固体与液体、粒径差 | 难溶固体与溶液 |
| 结晶 | 溶解度及其温度变化 | 可溶性固体 |
| 蒸馏 | 沸点差 | 互溶液体或溶剂回收 |
| 分液 | 液体互不相溶、密度不同 | 萃取后的两液层 |
| 萃取 | 溶质在两溶剂中溶解度不同 | 从水相转入有机相 |
| 升华 | 固体挥发性差异 | 碘等易升华物质 |

## 提纯与检验原则

- 除杂试剂应过量适度、不引入新杂质，生成物易分离，并尽量不损失主要物质。
- 鉴别要有不同现象；检验需设置空白、对照或排除干扰，不能把现象直接等同于唯一结论。
- 常见气体检验要区分“检验”和“吸收”：例如石灰水可检验少量 $ce{CO2}$，浓碱液更适合吸收。

## 典型方法与例题

**例** 除去 $ce{CO2}$ 中的少量 $ce{HCl}$，可通过饱和 $ce{NaHCO3}$ 溶液；不能用强碱，因为会同时吸收 $ce{CO2}$。

## 易错提醒

萃取剂须与原溶剂互不相溶且不与溶质反应；分液漏斗振荡后要放气。检验硫酸根应先排除能与钡离子形成沉淀的干扰离子。

## 自测

1. 从含少量泥沙的硝酸钾溶液获得较纯晶体，应依次采用哪些操作？
2. 用新制氯水和四氯化碳能否鉴别溴离子和碘离子？

::: details 答案
1. 过滤、蒸发浓缩、冷却结晶、过滤、洗涤、干燥。2. 能，氧化后有机层分别呈橙红色和紫红色。
:::
