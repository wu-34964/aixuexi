# 氯及其重要化合物

## 考点定位

掌握氯气、含氯消毒剂、卤素和卤离子的性质，理解氯气制备、净化、收集与尾气处理。

## 核心知识清单

- 氯气黄绿色、有刺激性气味、有毒，密度比空气大，能溶于水；实验室通常向上排空气法或排饱和食盐水法收集。
- 氯水含 $ce{Cl2}$、$ce{H2O}$、$ce{HClO}$、$ce{H+}$、$ce{Cl-}$、$ce{ClO-}$ 等粒子，兼有酸性、氧化性和漂白性。
- 次氯酸见光分解；漂白粉有效成分为 $ce{Ca(ClO)2}$，空气中生成 $ce{HClO}$ 后发挥作用。
- 卤素单质氧化性一般为 $ce{Cl2>Br2>I2}$；检验卤离子要先用稀硝酸酸化，再加硝酸银。

## 重要反应

$$\ce{MnO2 + 4HCl(conc.) ->[\Delta] MnCl2 + Cl2 ^ + 2H2O}$$
$$\ce{Cl2 + H2O <=> HCl + HClO}$$
$$\ce{Cl2 + 2OH- -> Cl- + ClO- + H2O}$$

## 典型方法与例题

**例** 干燥氯气不能使干燥有色布条褪色，而湿润布条褪色，说明直接起漂白作用的是氯气与水形成的次氯酸。

## 易错提醒

氯气与水的反应可逆，不能写等号；漂白是氧化作用且不可逆。用浓盐酸制氯气时产生的气体要依次除 $ce{HCl}$ 和水蒸气。

## 自测

1. 写出氯气氧化溴离子的离子方程式。
2. 氯气尾气为何常用碱液而不用澄清石灰水？

::: details 答案
1. $\ce{Cl2 + 2Br- -> 2Cl- + Br2}$。2. 石灰水浓度低、吸收能力有限，浓碱液吸收更充分。
:::
