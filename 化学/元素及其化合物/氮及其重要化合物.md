# 氮及其重要化合物

## 考点定位

掌握氮气、氨、铵盐、氮氧化物和硝酸的性质及含氮物质转化。

## 核心知识清单

- $ce{N2}$ 键能大，常温稳定；高温或放电时可与氧气反应。
- 氨易溶于水、呈碱性，能与酸形成铵盐，也可被催化氧化；实验室用铵盐与强碱加热制取。
- 铵盐受热性质取决于阴离子；检验 $ce{NH4+}$ 要加碱并加热，用湿润红色石蕊试纸检验逸出气体。
- $ce{NO}$ 无色，遇空气迅速变为红棕色 $ce{NO2}$；$ce{NO2}$ 与水反应生成硝酸和一氧化氮。
- 硝酸是强酸和强氧化剂，与金属反应通常不放氢气。

## 重要反应

$$\ce{4NH3 + 5O2 ->[催化剂][\Delta] 4NO + 6H2O}$$
$$\ce{3NO2 + H2O -> 2HNO3 + NO}$$
$$\ce{NH4+ + OH- ->[\Delta] NH3 ^ + H2O}$$

## 典型方法与例题

**例** 将装有 $ce{NO2}$ 的试管倒立水中并通入适量氧气，$ce{NO}$ 被氧化后继续与水反应，气体可被更充分吸收。

## 易错提醒

浓、稀硝酸与铜的主要还原产物分别为 $ce{NO2}$、$ce{NO}$，但实际产物受浓度等条件影响。氨的喷泉实验说明其溶解度大，不单独证明氨水呈碱性。
