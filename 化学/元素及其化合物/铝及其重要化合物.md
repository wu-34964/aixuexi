# 铝及其重要化合物

## 考点定位

掌握铝及其氧化物、氢氧化物的两性，分析铝盐与强碱反应的量变过程。

## 核心知识清单

- 铝是活泼金属，但致密氧化膜使其有较强抗腐蚀性；常温下在浓硫酸、浓硝酸中钝化。
- $ce{Al2O3}$、$ce{Al(OH)3}$ 都具有两性，可与强酸、强碱反应。
- 铝盐遇少量强碱先生成 $ce{Al(OH)3}$，强碱过量时沉淀溶解；偏铝酸盐通入适量 $ce{CO2}$ 可制得氢氧化铝。

## 重要反应

$$\ce{2Al + 2OH- + 2H2O -> 2AlO2- + 3H2 ^}$$
$$\ce{Al^3+ + 3OH- -> Al(OH)3 v}$$
$$\ce{Al(OH)3 + OH- -> AlO2- + 2H2O}$$

水溶液中偏铝酸根也常写作 $\ce{[Al(OH)4]-}$，答题时应与题目给定形式保持一致。

## 典型方法与例题

**例** 向含 $1\,\mathrm{mol}\,\ce{Al^3+}$ 的溶液逐滴加入强碱：生成沉淀最多需 $3\,\mathrm{mol}\,\ce{OH-}$，使沉淀完全溶解共需 $4\,\mathrm{mol}\,\ce{OH-}$。

## 易错提醒

$\ce{Al(OH)3}$ 只与强碱明显反应，不与弱碱氨水反应，因此常用氨水沉淀铝离子。铝热反应不是所有金属氧化物都能发生。

## 自测

1. 写出偏铝酸盐溶液通入过量 $ce{CO2}$ 的离子方程式。
2. 为什么不能用强碱从含镁、铝离子的混合液中一次性同时沉淀两者？

::: details 答案
1. $\ce{AlO2- + CO2 + 2H2O -> Al(OH)3 v + HCO3-}$。2. 强碱过量会使氢氧化铝溶解。
:::
