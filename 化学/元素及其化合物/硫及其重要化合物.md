# 硫及其重要化合物

## 考点定位

建立硫元素 $-2、0、+4、+6$ 价的转化网络，掌握二氧化硫、硫酸及硫酸根检验。

## 核心知识清单

- 硫单质常表现氧化性，与强氧化剂反应时也可表现还原性。
- $ce{SO2}$ 是酸性氧化物，兼具还原性、氧化性和漂白性；其漂白通常是化合反应，受热可恢复。
- 浓硫酸具有吸水性、脱水性和强氧化性；稀硫酸主要表现强酸性。
- 检验 $ce{SO4^2-}$：先加稀盐酸排除 $ce{CO3^2-}$、$ce{SO3^2-}$ 等干扰，再加 $ce{BaCl2}$。

## 重要反应

$$\ce{SO2 + 2H2S -> 3S v + 2H2O}$$
$$\ce{SO2 + Cl2 + 2H2O -> H2SO4 + 2HCl}$$
$$\ce{Cu + 2H2SO4(conc.) ->[\Delta] CuSO4 + SO2 ^ + 2H2O}$$

## 典型方法与例题

**例** $ce{SO2}$ 使酸性高锰酸钾褪色体现还原性，使品红褪色体现漂白性；现象相同但原理不同。

## 易错提醒

$\ce{SO2}$ 漂白不能用于酸碱指示剂的简单判断；浓硫酸与铜需加热，反应停止后仍可能有硫酸剩余。

## 自测

1. $ce{SO2}$ 通入 $ce{BaCl2}$ 溶液是否必然产生沉淀？
2. 写出酸性条件下 $ce{SO2}$ 被 $ce{MnO4-}$ 氧化的离子方程式。

::: details 答案
1. 不会，亚硫酸酸性条件下不能提供足够的亚硫酸根；若有氧化剂则可能生成硫酸钡。2. $\ce{5SO2+2MnO4-+2H2O -> 5SO4^2-+2Mn^2++4H+}$。
:::
