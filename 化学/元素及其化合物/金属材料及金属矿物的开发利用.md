# 金属材料及金属矿物的开发利用

## 考点定位

认识合金性能、金属冶炼方法及资源综合利用，能根据金属活动性选择冶炼路线。

## 核心知识清单

- 合金是金属与其他金属或非金属熔合形成的金属材料，通常硬度更大、熔点更低，性能可调。
- 活泼金属（如钠、镁、铝）常用电解熔融盐或氧化物冶炼；中等活泼金属常用热还原；不活泼金属可用热分解或湿法冶金。
- 铝用电解熔融 $ce{Al2O3}$ 制备而非电解水溶液；铁主要由高炉炼铁获得生铁，再炼钢调节碳含量。
- 矿物开发需兼顾富集、冶炼、尾气处理、废渣利用与金属回收。

## 重要反应

$$\ce{Fe2O3 + 3CO ->[高温] 2Fe + 3CO2}$$
$$\ce{2Al + Fe2O3 ->[高温] Al2O3 + 2Fe}$$
$$\ce{Fe + CuSO4 -> FeSO4 + Cu}$$

## 典型方法与例题

**例** 不能用焦炭直接还原氧化铝制铝，因为铝的还原性强、氧化物稳定，工业上采用熔融电解法。

## 易错提醒

电解法冶炼的原料必须熔融且能导电；不能把“所有不活泼金属均游离存在”绝对化。合金仍属于混合物。

## 自测

1. 湿法炼铜利用了什么反应原理？
2. 为什么钢通常比纯铁应用更广？

::: details 答案
1. 较活泼金属置换较不活泼金属。2. 合金的强度、硬度和耐腐蚀等性能可按用途调节。
:::
