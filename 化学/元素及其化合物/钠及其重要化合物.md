# 钠及其重要化合物

## 考点定位

掌握钠、氧化钠、过氧化钠、碳酸钠和碳酸氢钠的性质、转化与实验判断。

## 核心知识清单

- 钠质软、密度小、熔点低，保存于煤油或石蜡油中；与水反应表现为浮、熔、游、响、红。
- $ce{Na2O}$ 是碱性氧化物；$ce{Na2O2}$ 含过氧键，既有强氧化性，也可与水或 $ce{CO2}$ 放出氧气。
- $ce{Na2CO3}$ 热稳定、碱性较强；$ce{NaHCO3}$ 溶解度较小，受热分解，碱性较弱。

## 重要反应

$$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$$
$$\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$$
$$\ce{2NaHCO3 ->[\Delta] Na2CO3 + CO2 ^ + H2O}$$

鉴别等浓度碳酸盐和碳酸氢盐可测 pH、滴加 $ce{BaCl2}$ 或利用热稳定性；滴加酸时两者最终均放出 $ce{CO2}$，要关注滴加顺序与现象阶段。

## 典型方法与例题

**例** 向 $ce{Na2CO3}$ 溶液逐滴加盐酸，先发生 $ce{CO3^2- + H+ -> HCO3-}$，再发生 $ce{HCO3- + H+ -> CO2 + H2O}$；因此开始可能无气泡。

## 易错提醒

钠着火不能用水或泡沫灭火器；应用干燥沙土。焰色试验是元素性质，观察钾的紫色需透过蓝色钴玻璃。

## 自测

1. $ce{Na2O2}$ 与水反应时氧化剂和还原剂是否为不同物质？
2. 除杂：$ce{Na2CO3}$ 固体中混有少量 $ce{NaHCO3}$，应怎样处理？

::: details 答案
1. 不是，过氧化物发生歧化。2. 充分加热。
:::
