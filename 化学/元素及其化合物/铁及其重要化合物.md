# 铁及其重要化合物

## 考点定位

围绕 $ce{Fe^0}$、$ce{Fe^2+}$、$ce{Fe^3+}$ 的转化判断氧化还原反应，并掌握氢氧化物和铁离子的检验。

## 核心知识清单

- 铁与弱氧化性酸生成 $ce{Fe^2+}$，与足量氯气等强氧化剂生成 $ce{Fe^3+}$；常温下浓硫酸、浓硝酸使铁钝化。
- $ce{Fe^2+}$ 浅绿色、还原性较强；$ce{Fe^3+}$ 棕黄色、具有氧化性。
- $ce{Fe(OH)2}$ 白色絮状沉淀极易被空气氧化，现象为白色迅速变灰绿，最终红褐色。
- $ce{Fe^3+}$ 遇 $ce{SCN-}$ 显血红色；检验 $ce{Fe^2+}$ 可先加 $ce{KSCN}$ 无明显现象，再加氧化剂显红色。

## 重要反应

$$\ce{2Fe^3+ + Fe -> 3Fe^2+}$$
$$\ce{2Fe^2+ + Cl2 -> 2Fe^3+ + 2Cl-}$$
$$\ce{4Fe(OH)2 + O2 + 2H2O -> 4Fe(OH)3}$$

## 典型方法与例题

**例** 除去 $ce{FeCl2}$ 溶液中的少量 $ce{FeCl3}$，加入足量铁粉后过滤，既引入目标元素又把 $ce{Fe^3+}$ 还原为 $ce{Fe^2+}$。

## 易错提醒

加入 $ce{KSCN}$ 后无红色不能直接证明存在 $ce{Fe^2+}$；还需后续氧化形成对照。酸性高锰酸钾检验 $ce{Fe^2+}$ 时要排除 $ce{Cl-}$ 等还原性离子的干扰。
