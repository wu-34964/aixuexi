# 英语写作

高考写作考查的是完成交际任务和连贯表达，不是背诵华丽句型。不同地区的写作题型可能不同，训练时应以本省当年考试说明与真题为准。

## 两类核心任务

- [应用文写作](./应用文写作)：写清身份、目的、要点和期望回应。
- [读后续写](./读后续写)：在原文约束下续写合理情节，保持人物和主题一致。

## 通用写作流程

1. 圈出身份、对象、目的、内容要点和语气。
2. 用中文或关键词列出段落功能，不先追求复杂句。
3. 写出主干，再用从句、非谓语或介词短语补充细节。
4. 检查任务点、谓语、名词单复数、拼写、标点和字数要求。

## 建议积累方式

按功能积累表达，例如“说明目的、提出建议、表达感谢、推进情节”，而不是整篇背模板。每个表达都配一个自己的例句，并定期替换语境复写。
