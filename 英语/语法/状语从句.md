# 状语从句

## 考查目标

判断主从句之间的时间、条件、原因、让步、目的、结果、比较等逻辑关系。

## 核心知识

- 时间：*when, while, before, after, until, as soon as*。
- 条件：*if, unless, as long as*。
- 原因与结果：*because, since, so...that*。
- 让步：*although, though, even if/though*。
- 目的：*so that, in order that*。

在时间和条件状语从句中，谈论将来时常用一般现在时代替一般将来时。

## 操作步骤

1. 分清主句和从句。
2. 用直白中文概括两句逻辑。
3. 选择连接词并检查是否与其他连词重复。
4. 检查时态呼应和否定范围。

## 典型例题

We will start the activity as soon as everyone arrives. 从句表达将来时间，但使用一般现在时 *arrives*。

## 易错点

同时使用 *although...but* 或 *because...so*；混淆 *unless* 与 *if*；只看单句不判断逻辑。

## 自测题

1. ___ you keep practicing, you will improve.
2. We stayed indoors ___ the rain stopped.
3. ___ the task was difficult, the students completed it.
4. I wrote down the address so that I ___ not forget it.（will/would）

<details><summary>查看答案</summary>

1. If/As long as。
2. until。
3. Although/Though。
4. would；主句为过去时，表示过去视角下的目的。
</details>

## 复习建议

按逻辑功能整理连接词，并为易混词各写一个对比例句。
