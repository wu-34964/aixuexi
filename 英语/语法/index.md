# 英语语法

语法的作用是判断句子结构和表达关系。学习时先找谓语，再分析主干与修饰，不把规则背成孤立清单。

## 推荐顺序

1. [句子成分与基本句型](./句子成分与基本句型)
2. [时态语态](./时态语态)与[主谓一致](./主谓一致)
3. [非谓语动词](./非谓语动词)
4. [三大从句](./三大从句)
5. [特殊句式](./特殊句式)
6. [长难句分析](../长难句/)

## 判断语法题的通用流程

1. 观察空格在句中的功能。
2. 圈出谓语，判断句中是否缺谓语。
3. 检查主被动、时间、单复数和逻辑关系。
4. 代回完整句子，确认形式与意思同时成立。
