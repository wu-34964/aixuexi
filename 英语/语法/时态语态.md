# 时态语态

## 考查目标

根据时间线、上下文和主谓关系选择动词的时态与语态。

## 核心知识

- 一般现在时：事实、习惯、稳定状态。
- 一般过去时：过去发生并结束的动作。
- 现在完成时：过去动作与现在有关，常见 *since, so far, in recent years*。
- 过去完成时：在另一个过去动作之前已经完成。
- 进行时：某一时点正在进行，或强调阶段性。
- 被动语态：主语是动作承受者，结构为 *be + done*。

## 操作步骤

1. 找时间标志，但不只依赖标志词。
2. 画出动作在时间线上的先后。
3. 判断主语执行还是承受动作。
4. 检查助动词的人称、数和形式。

## 典型例题

By the time we arrived, the lecture **had begun**. “到达”和“开始”都在过去，而开始更早，所以用过去完成时。

## 易错点

见 *since* 就忽略主从句关系；被动语态漏写 *be*；把不及物动词用于被动。

## 自测题

1. Great changes ___ (take) place in the town in recent years.
2. The bridge ___ (complete) last year.
3. When I entered, the students ___ (discuss) the project.
4. By last Friday, we ___ (collect) enough information.

<details><summary>查看答案</summary>

1. have taken；*take place* 无被动。
2. was completed。
3. were discussing。
4. had collected。
</details>

## 复习建议

错题复盘时画时间线，并明确“谁做动作”，比背时间标志词更可靠。
