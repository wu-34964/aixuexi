# 高考任务训练

本模块把基础词汇、语法和语篇能力应用到真实题型。不同地区的题目组合可能不同，请按本省要求选择训练内容。

## 学习顺序

1. [阅读理解](./阅读理解)：训练定位、概括与推断。
2. [七选五](./七选五)：训练句间衔接和段落结构。
3. [完形填空](./完形填空)：训练词义、搭配和篇章逻辑。
4. [语法填空](./语法填空)：训练句法判断和词形变化。
5. [听力](../听力/)：训练连续语流中的预测与信息筛选。

## 训练原则

- 第一次限时完成，保留真实作答痕迹。
- 每道错题必须找到文本证据或语法依据。
- 将错因归入词汇、结构、定位、逻辑或表达。
- 回到[词汇](../单词/)、[语法](../语法/)和[长难句](../长难句/)补缺，再做同类题验证。

正确率只是结果；能够稳定复现判断过程，才说明能力真正形成。
