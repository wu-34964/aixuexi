# 固定搭配与短语

## 考查目标

识别并准确使用动词、介词、名词和形容词的稳定组合，提高完形、语法填空和写作表现。

## 核心知识

| 类型 | 示例 |
| --- | --- |
| 动词 + 介词 | depend on, result in, contribute to |
| 形容词 + 介词 | aware of, responsible for, familiar with |
| 名词 + 介词 | access to, approach to, effect on |
| 动词 + 名词 | draw a conclusion, take measures, meet a need |

注意：*to* 可能是介词，也可能是不定式符号。*look forward to doing* 中的 *to* 是介词。

## 操作步骤

1. 以完整词块为单位识别，不逐词翻译。
2. 检查介词后接名词、代词还是动名词。
3. 写作前优先选择自己能确认的搭配。

## 典型例题

The activity provided students **with** an opportunity to learn about local culture.

结构为 *provide sb with sth*，也可写成 *provide sth for sb*。

## 易错点

混淆 *result in*（导致）与 *result from*（由……造成）；把中文搭配逐词直译；漏掉冠词或介词。

## 自测题

1. Hard work can result ___ progress.
2. We look forward to ___ (hear) from you.
3. 改错：Students have easy access of the library.
4. 用 *take measures to do* 写一句环境主题句。

<details><summary>查看答案</summary>

1. in。
2. hearing。
3. 将 *of* 改为 *to*。
4. 示例：We should take measures to reduce plastic waste.（开放性答案，搭配正确即可。）
</details>

## 复习建议

从真题中按中心词整理词块，并用替换主语、时态和宾语的方式复写。
