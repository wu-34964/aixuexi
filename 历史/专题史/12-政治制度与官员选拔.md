## 知识点1 中国古代政治制度的形成与发展

| 先秦时期的政治制度 | 1.夏朝：约公元前2070年，禹死后,其子启继位,打破了原始民主制下的禅让政治传统,世袭制代替了禅让制。<br>【易错点拨01】禅让制与世袭制<br>(1)“禅让制”是原始社会末期形成的政治制度,它代表当时落后的生产力水平。<br>(2)“世袭制”是社会生产力发展的结果,是与私有制相适应的。世袭制顺应了历史发展的趋势,是一种进步的历史现象。<br>2.商朝：<br>(1)内外服制：商王直接控制内服王畿地区，王畿四周是外服。（商王对其控制有限），中央政权与各附属国之间的联系较为松散。<br>(2)管理机构：已经有较系统的国家机构和分掌内外服各类事务的官吏。<br>3.西周：<br>(1)分封制:<br>①分封对象:同姓贵族、异性功臣或旧贵族;<br>②分封序列:天子--诸候--卿大夫--士;<br>③权利:享有分封土地上的统治权(设置官员、建立武装，征发赋役》；在自己的封地内实行再分封；<br>④诸侯义务:服从周天子的政令，承担对周王室的义务(镇守疆土、随从作战、缴纳贡赋和朝歡述职)；<br>⑤影响：形成对周王室众星捧月般的政治格局；开发了边远地区，扩大了统治区域；促进经济文化交流和民族交融，为华夏族的形成奠定了基础（积极）。但诸侯国有相当大的独立性，埋下分裂割据的隐患（消极）。<br>(2)宗法制:<br>①含义:按父系血缘关系亲疏来决定继承权利维系政治等级、巩固国家统治制度。<br>②目的:加强分封制形成统治秩序，解决贵族之间在权力财产和土地继承上矛盾。<br>③核心:嫡长子继承制。<br>(2)分封制与宗法制的关系:互为表里分封制是家法制在政治上的体现，宗法制是分封制实行的基础。<br>(4)政体特征:分封制和宗法制相配合，政治权力分配与血缘关系相结合。<br>4.中国古代早期政治制度的基本特点：<br>（1）以血缘关系为纽带：将国家权力和家庭关系结合起来，形成“家国一体”的局面。<br>（2）等级森严：以分封制和宗法制为核心形成了“天子—诸侯—卿大夫—士”的等级序列。不同等级的权利和义务固定，很难逾越。<br>（3）地方权力较大：分封制给予诸侯国较大的统治权力，最高统治者尚未实现权力高度集中。<br>（4）神权色彩浓厚：王权和神权紧密结合。<br>（5）稳定延续：夏商周政治制度前后沿袭，具有相对的延续性和稳定性。<br>5.春秋战国时期的政治制度<br>(1)春秋：随着社会经济发展和宗法血缘关系的瓦解，贵族等级分封制开始解体。<br>(2)战国：为适应社会变化的需要，各国在政治上进行了重大改革，君主权力加强，郡县制、官僚制等封建政治制度开始产生。 |

| 秦朝的政治制度 | 1.背景：秦的统一结束了长期战争的混乱局面，在全国范围内建立起中央集权的政治制度。<br>2.内容：<br>（1）皇帝制度（皇帝独尊、皇权至上、皇位世袭）：秦朝政治制度的核心，一切事务的决定权都在皇帝手中。<br>（2）三公九卿制：①丞相：百官之长，分左、右，秉承皇帝旨意，统领众官，丞相府是行政中枢所在。②太尉：最高武官，掌军事（形同虚设，军权掌握在皇帝手中）。③御史大夫：副丞相，协理国政，掌管图籍、文书，又是最高监察官。④三公之下是分掌国家各种政务和皇室事务的卿，泛称“九卿”；九卿下设若干部门，处理具体事务。<br>（3）郡县制（官僚政治取代贵族政治的重要标志）<br>①地方行政机构分郡、县两级，主要官吏都由中央直接任命。<br>②郡是地方最高行政机构，置郡守、郡丞和郡尉，另设监御史掌监察。<br>③郡下设县或道，根据户数的多少，置县令（长）、县丞、县尉。<br>（4）文书行政管理制度：以文书推行行政管理，建立了以邮传为中心的文书传送系统，以保障皇帝和中央的政令能够传送到全国各地。 |
| 两汉至明清时期中央官制的演变 | 1.中央行政制度<br>（1）汉朝：<br>①汉承秦制，中央行政制度仍为三公九卿制。汉武帝设立中朝（包括侍中、常侍等，出身不高，品秩较低），中央行政中枢的权力逐渐由丞相转移到皇帝亲信手中，从而使外朝丞相的权力大大削弱。<br>②西汉晚期，中朝尚书的权力逐渐增大。东汉时，尚书台为新的行政中枢，三公权力受到削弱。<br>（2）隋唐：三省六部制（相权被制度化地一分为三）<br>①内容：三省是由皇帝直接掌控的中枢。中书省是受命于皇帝的决策机构，门下省是审议封驳朝廷政令的机构，尚书省是执行机构，下设吏、户、礼、兵、刑、工六部。三省长官中书令、门下侍中、尚书令与尚书仆射并称宰相，分掌宰相职权，他们共同议政的地方叫政事堂。<br>②特点：体系完整，职责分明，相互制约，可以有效履行封建国家的不同职能。<br>（3）宋朝<br>①最高行政长官是同中书门下平章事，为宰相之职。<br>②设枢密院掌管军政（二府三司制；同时设参知政事为副相，分割行政权），三司掌握财政大权，分割宰相的权力。<br>（4）元朝：实行中书省总理全国政务的中枢制度。<br>（5）明朝：①明太祖废除中书省和宰相。②内阁大学士协助皇帝处理各种政务，内阁（明成祖时正式设立，后掌握“票拟权”）逐渐成为事实上的行政中枢。<br>（6）清朝：雍正帝设立军机处，军机大臣直接秉承皇帝旨意，处理军国大事。军机处逐渐成为掌管处理全国军政事务的中枢。<br>演变趋势：君权不断强化，相权逐步分散、削弱，直至被废除。<br>2.地方行政制度（趋势：削弱地方权力、加强中央集权）<br>（1）汉朝：<br>①西汉：沿袭秦朝的郡、县二级制，汉初还包括王国和侯国。景帝、武帝后，诸侯国的权力被不断削弱，不再对中央构成威胁。<br>②东汉晚期：监察区“州”变为一级行政机构，形成州、郡、县三级制；州刺史不仅有行政权，还有领兵权，形成内轻外重、干弱枝强的局面。<br>（2）魏晋南北朝：主要是州、郡、县三级制。<br>（3）隋朝：实行州、县二级制。<br>（4）唐朝：根据山川形势把全国划分为10道，后增至15道，作为中央派出的监察机构。后来，道变成州、县以上的一级行政实体。唐中期以后，设节度使统兵征战，形成藩镇割据势力。<br>（5）宋朝：实行路、州（府）、县三级制。<br>（6）元朝：实行行省（我国省制的开端，提高了行政效率，加强了中央集权）制度，形成省、路、府、州、县多级行政制度。<br>（7）明清：<br>①明：明初废行中书省,由布政使司、按察使司、都指挥使司分割其权力;朝廷向各省派出巡抚、巡按,逐渐总揽一省之权。<br>②清：省、府、县三级制;巡抚成了一省长官,又设总督掌管一省或数省军政大权 |

## 知识点2 对中国古代专制主义中央集权制度演变的规律性认识

1.经济基础：自然基础具有很强的分散性，需要一个强有力的中央政府来维护国家的统一和社会的稳定。

### 2.两大矛盾与发展趋势：

（1）两大矛盾：一是君权与相权的矛盾，二是中央集权与地方分权的矛盾。

（2）发展趋势：君权不断加强，相权不断削弱直至被废除；中央权力不断强化，地方权力不断削弱。

3.总体特征：（1）皇位世袭、皇帝独尊、皇权至上；（2）从中央到地方主要官吏均由皇帝任免；（3）实行文化专制；（4）带有浓厚的人治色彩。

4.总体评价：从整个历史进程来看，具有双重性。在封建社会前期，其积极作用是主要的，在封建社会后期，其消极作用则是主要的，尤其是明清时期，专制主义中央集权的强化严重阻碍了资本主义萌芽的发展和社会进步。

5.中国古代统治者防止地方割据、加强地方管理的方式：（1）分化事权，相互牵制；（2）进行适当的行政区划；（3）实行监察制度；（4）中央直接掌控地方权力或设置专门机构直接管理；（5）实行一些特殊的管理制度。

6.古代中国地方行政区划的基本原则：山川形便、犬牙交错。

7.中国古代地方行政制度演变的规律性认识：（1）中央集权是变化的主因；（2）分权、相互制约是机构改革的基本方法；（3）继承性与创新性：既沿袭前代制度，又不断改进、创新；（4）下稳上动：县级相对稳定，县之上变动较大；⑤监察区多变为新的行政区。

## 知识点3 西方国家古代和近代政治制度的演变

| 古希腊罗马的政治制度 | 1.雅典——民主政治<br>国家权力掌握在公民大会、议事会、官员和公民法庭手中。<br>(1)内容：①公民大会由全体成年男性公民组成,是国家最高权力机关,决定国家法律和政策。②议事会议员从公民中抽签产生,主要负责为公民大会准备决议草案,并参与国家日常管理。③大部分官员由抽签产生,大多一年一任,随时可以被罢免和审判。④公民法庭是主要司法机关。<br>(2)实质:建立在奴隶制度之上的民主。<br>2.斯巴达——寡头政治<br>(1)公民大会名义上是国家最高权力机关,但王位世袭，国王垄断军事统帅权。<br>(2)长老会议员终身任职。<br>(3)监察官拥有主持公民大会、审判国王等重要权力。<br>3.罗马共和国——贵族寡头政治<br>国家权力由执政官、元老院和公民大会掌握。<br>(1)执政官由全体公民选举产生,主要职责是担任军事统帅,主持公民大会和元老院,并执行相关决议。<br>(2)元老院由卸任高级官员组成,终身任职,负责向官员提出建议,协调他们的行动。<br>(3)公民大会是罗马国家最高权力机关,但其召开和表决受到高级官员和元老院的限制,难以有效发挥作用。<br>4.罗马帝国——君主政治<br>公元前1世纪末,罗马共和国崩溃,屋大维建立元首制形成君主政治,实行独裁统治。<br>5.局限性:无论是希腊城邦,还是罗马共和国,公民都是少数。妇女、外邦人和奴隶不仅没有资格参与政治,还受到剥削和多种压迫。 |

| 中古西欧的封建制度 | 1.中古西欧政治的特点：<br>（1）前期：①封君封臣制度；②王权与教权长期并立，教权高于王权。<br>（2）后期：王权衰而复振，英法等国出现议会君主制和等级君主制。<br>2．中古西欧国家的概况<br>(1)建立：在罗马帝国的废墟和日耳曼人王国的基础上建立。<br>(2)发展：法兰克王国的查理大帝一度建立起庞大帝国。他死后，国家陷入分裂形成后世三个主要国家法国、德国和意大利的雏形。<br>(3)特征：①以封君、封臣为基本特征。②世俗王权和基督教会长期并立时有冲突。<br>3.中古西欧封建制度的典型代表<br>（1）法国的等级君主制<br>①标志：在走向统一国家的过程中，国王与教会冲突不断。14世纪初，由教士、贵族和城市市民代表组成的三级会议召开。<br>②作用：三级会议的召开，标志着法国进入等级君主制阶段；国王与贵族、教会、市民通过三级会议相互合作，有利于进一步强化王权 。<br>（2）英国的议会制度<br>①《大宪章》的签署：<br>A背景：13世纪初，英王约翰奉行的内外政策失败，遭到贵族、骑士和市民反对，他们迫使国王签署《大宪章》（英国封建时期重要宪法性文件，影响了近代资本主义制度确立）<br>B内容：肯定了国王的合法地位与人身的神圣不可侵犯，同时保障封建主的特权，并适当照顾骑士和市民的利益<br>②议会制度的确立：国王通过议会为自己的政策寻求支持；议会以向国王请愿的形式，要求国王改善统治（逐渐形成召开议会限制王权的传统）。 |

## 知识点8 全面认识中国古代的变法和改革

从原因上看：旧的生产关系阻碍了社会生产力发展；为了达到某一政治目的,实现富国强

兵；顺应历史发展潮流或社会发展趋势；少数民族进入中原地区，学习汉族先进制度和文化。民族交融加强；统治阶级面临严重统治危机，为抑制土地兼并，缓和阶级矛盾，增加财政收入。

2.从目的上看：根本目的是巩固统治。

3.从内容上看：调整生产关系,改革土地制度和赋役制度;采取措施恢复、发展经济;整顿吏治,改革军制;开源节流,增加财政收入;学习先进的政治制度和文化;等。

4.从失败原因上看：改革触动了守旧势力的利益,遭到他们的强烈反对;用人不当或操之过急,

新的举措有些会损害百姓的利益;等。

5.从成功原因上看：顺应历史发展潮流或社会发展趋势;改革者或为最高统治者,或赢得最高

统治者的充分信任和支持;制定了顺应社会发展潮流并切实可行的改革措施;改革者具有坚强的意志和百折不挠的决心等。

## 知识点9 中国改革规律总结

（1）改革类型：促进社会转型的改革、拯救危局的改革、少数民族学习汉族先进制度和文化的改革。

（2）对改革原因（背景）的综合认识：①旧的生产关系阻碍了社会生产力的发展；②统治阶级面临严重的统治危机，为抑制土地兼并、缓和阶级矛盾、增加财政、实现富国强兵收入而进行改革；③顺应历史发展潮流或者社会发展趋势；④民族危机严重，为拯救国家危亡进行改革。⑤少数民族改革与少数民族进入中原，为学习先进制度和文化，加速本民族封建化。

决定改革成败的因素：①改革是否顺应历史发展的潮流和社会发展规律；②是否有支持改革的阶级基础和经济基础；③革领导者的指导思想和阶级基础；④是否采取了符合当时客观实际的措施；⑤是否有强大的政治力量作后盾.得到统治者或民众的支持

改革的认识和启示：①改革是历史发展的要求和产物 ；体现唯物史观。②改革社会弊政是促进国家强盛的手段；③符合社会发展规律和顺应人民愿望的进步改革，推动着社会进步和历史发展；④改革必然涉及某些人的特权和私利，因此改革是会有阻力，因而具有艰巨性和复杂性，不可能一帆风顺；⑤要注重结合本国国情，实事求是，与时俱进；⑥改革的措施必须行之有效，改革过程中要有用人得当，改革家要有远见卓识和坚定政治魄力。

## 知识点13 晚清时期选官制度的变革

### 1.晚清时期选官制度变革的特点

(1)晚清时期选官制度变革是清王朝在国内社会危机、各种权势集团的政治压力以及西方列强政治、经济、文化上的强大挑战下被迫作出的一种积极的政治反应,是对清王朝危亡形势的迫不得已的应战。

(2)废止科举取士制度,实行学堂选官、留学毕业生选官、议员选举,士绅参政,选拔军事人才等都是必然举措,而不纯粹是政治舞台上的骗局和闹剧。

(3)晚清选官制度变革奉行改制不改体,坚持实行封建专制制度,在政治上进行专制高压。

(4)晚清选官制度变革是各种政治力量较量的结果,为现代文官制度的出台奠基。

### 2.晚清选官制度变革的影响

(1)积极影响:推动了晚清官制改革,为社会发展积累了人才,推动了学堂教育的发展,在一定程度上适应了当时社会发展的需要。

(2)局限性:存在着急功近利、新旧杂陈、权限不清、职责不明等问题,变革的根本目的是维护封建专制统治。

有关政治制度名词：国家、国体、国家结构、政体等：

### 阐释

| 国家 | 指拥有共同语言、文化、种族、领土、政府或者历史的社会群体。马克思主义学说认为国家是阶级矛盾不可调和的产物，是经济上占统治地位的阶级镇压和剥削被压迫阶级的手段，国家是一种超越社会之上的公共权力，立法、行政和司法权。 |
| --- | --- |
| 国体 | 是指国家的性质，亦称国家的阶级本质。具体地说，就是社会各阶级在国家中所处的地位。统治阶级的性质决定着国家的性质，如奴隶制国家、封建制国家、资本主义国家和社会主义国家。我国的国体为“中华人民共和国是工人阶级领导的、以工农联盟为基础的人民民主专政的社会主义国家”。 |
| 国家结构 | 是一个国家地方与中央，整体与局部上的权力关系。一般分为单一制和复合制。其中复合制又包括了联邦制、邦联制等。单一制指若干不享有独立主权的行政区组成统一主权国家的制度。复合制是指由两个或两个以上政治实体组成的国家联盟的制度。联邦制是指由两个或两个以上邦或州联合组成一个统一国家的制度，州保留一定主权。邦联制在现代则一般是指一些国际间的区域组织，如欧盟。 |
| 政治制度 | 是指统治阶级为实现阶级专政而采取的统治方式、方法的总和。包括国家政权的组织形式、国家结构形式、政党制度及选举制度等。由于国家的类型不同，或同一类型国家所处的具体历史条件不同，其政治制度也会有差异。按政权的组织形式分，有君主制、共和制、议会制和人民代表制；按中央和地方管理的权限分，有中央集权制和地方分权制等。中国实行人民代表大会制的政权组织形式和单一制的国家结构形式。 |
| 政体 | 指政权的组织形式，即统治阶级采取什么样的方式来组织自己的政权机关。国体决定政体，政体反映国体。 |
| 民主制 | 多数人的统治。直接民主制是全体公民遵循多数统治的原则直接行使政治决策权的民主制度；间接民主制（代议制）是由选举产生，代表民意的机关来行使国家权力的方式，代议制是公民与国家之间的政治纽带，是现代民主政体的共同特征。 |
| 共和制 | 国家代表机关或国家元首由选举产生的一种制度。古罗马贵族共和制，现代多为民主共和制。民主共和制分为总统共和制和议会共和制。总统共和制：指由选民分别选举行政和立法机关，由总统担任国家元首，同时担任政府首脑制度。议会共和制：议会居于国家的政治中心地位，并通过议会来组织和监督政府的政治制度。 |
| 君主制 | 君主制：国家元首为世袭君主的政体。<br>等级君主制：君主依靠等级会议或议会实行统治。<br>君主专制政体：指以古代君王为核心的中央集权的政治体制，君王权力至高无上。<br>君主立宪制：在保留君主制的前提下，通过立宪，树立人民主权、限制君主权力的制度，包括议会制君主立宪制和二元君主立宪制（君主有实权）。 |
| 寡头政治 | 亚里士多德认为一人统治为君主政体，少数人统治为贵族政体，多数人统治为民主政体；而这三种政体之腐败形态，则为专制政治、寡头政治与暴民政治。 |
| 中央集权制 | 以国家职权统一于中央政府，削弱地方政府力量为标志的政治制度。君主专制必定中央集权，中央集权未必君主专制。中央集权强调中央和地方关系，君主专制强调君臣关系。 |
| 人民代表大会 | 是我国的根本政治制度，与我国国家政权的本质直接联系在一起，是中国国家政权人民性的集中体现。全国人民代表大会和地方各级人民代表大会都由民主选举产生，对人民负责，受人民监督。 |
| 政党制度 | 政党制度指的是一个国家通过政党进行政治活动的方式或状态。资本主义国家政党制度一般分为两党制、多党制和一党制。中国共产党领导的多党合作和政治协商制度是具有中国特色的社会主义政党制度。 |
| 民主集中制 | 民主集中制是我们党的根本组织原则和领导制度，是马克思主义政党区别于其他政党的重要标志，主要内容是个人服从组织，少数服从多数，下级服从上级，全党服从中央，听取下级意见，集体领导，禁止个人崇拜等。 |
