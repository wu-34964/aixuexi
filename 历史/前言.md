# 历史

本板块按照中国史、世界史和专题史整理高考历史一轮复习知识。建议先建立时空框架，再结合专题比较制度、经济、社会与文化的演变。

## 学习入口

- [中国史](./中国史/)：从中华文明起源到中国特色社会主义新时代。
- [世界史](./世界史/)：从早期文明到当代世界格局。
- [专题史](./专题史/)：政治制度、基层治理、经济生活与文化交流等跨时空主题。

## 使用建议

1. 先看每个专题开头的时空框架和考点速查。
2. 用“背景—内容—影响”或“原因—表现—评价”组织核心知识。
3. 对照表格完成同类制度、不同区域和不同时期的比较。
4. 复习后使用[历年真题](/tools/历年真题)检验知识迁移能力。
