# 命题与充分必要条件

## 考点概览

判断命题真假，写出含量词命题的否定，辨析充分条件、必要条件与充要条件。

## 知识与公式

- \(p\Rightarrow q\)：\(p\) 是 \(q\) 的充分条件，\(q\) 是 \(p\) 的必要条件。
- \(p\Leftrightarrow q\)：\(p\) 与 \(q\) 互为充要条件。
- 全称命题“\(\forall x\in M,p(x)\)”的否定为“\(\exists x\in M,\neg p(x)\)”。
- 存在量词命题“\(\exists x\in M,p(x)\)”的否定为“\(\forall x\in M,\neg p(x)\)”。
- 原命题与逆否命题等价。

## 典型方法

用集合包含判断条件关系：令 \(A\) 为满足 \(p\) 的对象集合、\(B\) 为满足 \(q\) 的对象集合，则 \(p\Rightarrow q\iff A\subseteq B\)。

## 例题解析

**例** “\(x>2\)”是“\(x^2>4\)”的什么条件（\(x\in\mathbb R\)）？

**解** \(x>2\Rightarrow x^2>4\)，但 \(x^2>4\) 还可能有 \(x<-2\)。故前者是后者的充分不必要条件。

## 易错提醒

否定全称命题时，量词和结论都要改变；“命题的否定”不是“否命题”。

## 自测

1. 写出“所有实数的平方都非负”的否定。
2. 判断：\(x=1\) 是 \(x^2=1\) 的必要条件。

::: details 答案
1. 存在实数 \(x\)，使 \(x^2<0\)。  
2. 错误；它是充分不必要条件。
:::
